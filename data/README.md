# Data

**No real data in this repository, ever.** This folder only describes where the data lives.

- `sources.yaml` lists every source this challenge may use: what it is, where to get it, under which licence, and who to ask. Fields marked `TODO` are not confirmed yet.
- Download data to `data/raw/`, which git ignores.
- On the HPE environment, the team's data is mounted read-only at `/data/<challenge>`.
- `../examples/` holds a small synthetic sample so the code runs anywhere.

Rules for the event: stand-in data only (public, synthetic, or collected on the day with consent); no identifiable clinical data.

Need a dataset that is not listed? Open an issue with the **Resource request** template.
