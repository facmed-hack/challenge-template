# FacMed Hack challenge — template

This is the template every FacMed Hack challenge repository starts from. In a challenge repository, this README holds the brief and, by the finals, the team's story: **the need · what we built · the result · next steps**.

- `CHALLENGE.md` — the full brief
- `AGENTS.md` — rules for coding agents (and humans)
- `NOTES.md` — the verification log
- `data/` — where the data lives (never the data itself)
